## Format

- **JPEG** (or PNG), portrait, taken on an iPhone simulator or device.
- Any modern iPhone resolution works (e.g. 1179×2556 or 1290×2796). The frame crops with
  `object-fit: cover`, so keep the important content away from the extreme edges.
- The page draws its own iPhone bezel and Dynamic Island — send the **raw screen capture**,
  not one already placed inside a device mockup.
- Keep each file under ~600 KB if you can; run them through ImageOptim or TinyPNG before
  committing so the page stays fast.
